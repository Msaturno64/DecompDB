# DecompDB

Port de PC de Dragon Ball Z Budokai Tenkaichi 3 (decomp) con el Tag Team Mod: hasta 10 jugadores online, gigantes y escenarios grandes, choques de rayos con Beam Assist. Tambien corre Budokai Tenkaichi 4 (TeamBT4 B14 REV2).

## Instalar

1. Descarga el zip de Releases y descomprimilo.
2. Abri Tenkaichi3Decomp-setup.exe y elegi tu ISO:
   - BT3: el disco de EE.UU. (SLUS-21678).
   - BT4: TeamBT4 B14 REV2 (SLUS_219.78.DBZBT4B14REV2.iso).
3. Toca Jugar.

El paquete no trae datos del juego: cada uno usa su propio ISO.

## Online

Dragon Net Battle o Tenkaichi Budokai Online, con codigo de sala. Todos tienen que usar la misma version.
